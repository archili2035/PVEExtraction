## 一、游戏简介

| 项目 | 内容 |
| --- | --- |
| 游戏名 | 超自然行动组（曾用代号：代号·超自然） |
| 出品/运营 | 巨人网络（上海巨人网络科技有限公司 / 巨人移动） |
| 玩法类型 | 中式微恐 · 搜打撤（搜索-战斗-撤离）多人合作手游 |
| 组队规模 | 4 人组队 PVE 合作生存 |
| 核心循环 | 进入恐怖场景 → 搜刮高价值道具（圣杯、雪莲、龙珠等）→ 对抗 AI 鬼怪 → 限时撤离 |
| 差异化定位 | 「中式微恐 + 搜打撤」，民俗符号（鬼新娘、青铜器、古墓）降低认知门槛 |

玩法要点：玩家不是孤独逃生者，而是分工明确的团队。恐怖感从「单纯恐惧」升级为「带目标的紧张」——例如「鬼新娘墓室」关卡需在限时内集齐三枚青铜镜启动升降梯，配合失误即团灭，由此催生「必须组队」的硬性社交需求。

## 五、段位设计

结论先行：**七级段位，由低到高为「实习生 → 助理 → 专员 → 精英 → 大师 → 王牌 → 超自然传说」**。其中「兔犬马牛熊虎狮」是段位的**动物图标**，不是段位名——真正承载段位语义的是职场职级。

| 等级 | 动物图标 | 段位名 |
| --- | --- | --- |
| 1 | 兔 | 实习生 |
| 2 | 犬 | 助理 |
| 3 | 马 | 专员 |
| 4 | 牛 | 精英 |
| 5 | 熊 | 大师 |
| 6 | 虎 | 王牌 |
| 7 | 狮 | 超自然传说 |

**三个来源拼合出的完整对应关系**：

- 七种动物徽章出自官网「段位图标更新」公告（[官网](https://www.chaoziran.com/news/56)，2025-05-22），官方以「超自然公司档案部绝密信件」的形式解释为远古山洞壁画图案，把段位晋升包装成「公司员工晋升制度」——段位系统本身即叙事的一部分。
- 四个高段位（精英/大师/王牌/超自然传说）的文字名与奖励出自「限定赛季奖励」公告正文（[官网](https://www.chaoziran.com/news/168)，2025-09-22）。
- 最低三档（实习生/助理/专员）出现在同篇 id168 的「段位继承规则图」中（该图临时链接已过期，内容由官方公众号版原文保留）。

**段位奖励梯度**（S1 结算口径，[官网](https://www.chaoziran.com/news/168)）：

| 段位 | 奖励 |
| --- | --- |
| 超自然传说 | 荣耀奖杯【秘境远征】（纯金质感，可陈列在梦居） |
| 王牌 | 限定头像框【摸金行动】 |
| 大师 | 左轮手枪首款皮肤【新星时代】 |
| 精英 | 专属头像【新星报道】 |

**易混点：段位 ≠ 职级**。游戏里另有一套「职级目标」（主界面 → 赛季 → 职级目标），是赛季手册里的**进度奖励**，按累计排位赛场次解锁（助理累计 3 场、专员 5 场、精英 5 场、大师 10 场，各领对应铲铲币），与段位分开结算。因职级也借用「助理/专员/精英/大师」等词，容易被误当作段位。

**设计要点**：把永久性晋升（动物徽章/职级成长）与赛季性竞争（实习生~超自然传说）解耦——动物徽章承担长线成长与世界观叙事，赛季段位承担周期性目标与稀缺外观发放（奖杯/头像框/皮肤均为陈列向外观，无一涉及数值），符合「外观商业化不卖数值」的整体路线。
