玩法框架

TPS 分析

TPS 与 FPS 的本质区别、视角（腰射 / 肩射 / FPP）与表现，供搜打撤射击玩法参考。

TPS 与 FPS 的本质区别

  • 镜头位置的区别
  • 进而视野大小、关卡尺寸、动画特效等一系列具体的感观区别
  • 从而带来大量的做法上的差异

视角

TPP Third Person Perspective（第三人称） TPP 腰射 TPP 肩射（OTS：Over-the-Shoulder 越肩视角瞄准）
FPP First Person Perspective（第一人称）

关键设计：TPP 与 FPP 之间的切换

向前推进镜头，某一帧切换 FPP。

表现

TPP 腰射

  • 武器动画（抖动）与镜头抖动
  • 动作与射击的结合

TPP 肩射

  • 拉近镜头：增加角色与枪械在镜头中的比例、让出视野中心给予射击目标、避免瞬切。
  • 对武器动画、角色动画、特效有更高要求。
  • 移动与射击状态切换的频率：从关卡、怪物、战斗节奏上需要避免过频繁地切换；移动与射击都可以保持较长的持续周期（《遗迹 2》的节奏挺舒适）。

FPP

同 FPS。

需要设计游戏不同射击的比例，从而确定资源投入重心。以《遗迹 2》为例，取消了 TPP 腰射，点击射击自动切换到肩射模式。

TPP 与 FPP 的表现差异

FPP
  • 关注武器本身的表现，至多增加弹出子弹与手部动画
  • 枪械击发时，武器本身结构变化以及反作用到镜头的变化
TPP
  • 核心参数：武器占屏幕的像素比（腰射 / 肩射各自不同）
  • 枪械操作时：武器本身结构变化占比变小、后座力作用到镜头效果变弱
  • 需重点强调后座力作用到角色模型的动画
  • 枪械相关动作需结合视角、突出角色原则重新设计
  • 强化开火特效、弹道线、命中特效
  • 纯写实的中规中矩的武器效果，可能天生不适配 TPS 游戏
  • 镜头跟随的绑定程度

关卡

  • 关卡尺寸等比放大，会带来比例认识偏差，因此更多偏向于室外开阔场景，或大型室内空间。
  • 因此题材上非绝对写实会更加适配。

其他问题

  • 枪口出的枪线，与镜头到准心连线的夹角问题：遮挡标识、弹道偏转。
  • 作为 PvP 的视角，存在信息不对称的情况，不适宜作为竞技 PvP 主视角（PUBG 的赛事也多采用 FPP），因此 TPP 下可能更多向娱乐化发展，而不是严肃竞技会好一些。
总结

TPP = 射击 + 动作

需要同时做好枪械射击。
